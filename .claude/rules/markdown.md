# Markdown

- markdownlint runs in the editor. Write to pass it: one H1 per file, blank lines around headings
  and fenced blocks, language tags on every fence, no trailing punctuation in headings.
- Tables: pad cells so the pipes align in every row (rule MD060). Reformat the whole table when
  a cell changes width.
- Links are relative paths from the file's location. Link to files and folders rather than
  naming them in prose.
- `README.md` is the index. Update its layout tree and tables when a course folder, skill, agent,
  tool, or nested project is added.
- Wrap prose at 100 columns to match the code line length. Lists over paragraphs; no emojis; no
  filler ("in this section we will").
- Don't create a README for a lesson folder unless the lesson asks for one.
